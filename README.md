# Clipvalley

A two-way clipboard for your devices. Paste text or an image on one, sign in on another, copy it back.

Sync follows your account rather than your hardware, so there is no pairing step. Any clip can be turned into a public read-only link, and switched off again at any time.

**Live at [clipvalley.vercel.app](https://clipvalley.vercel.app)**

## Running locally

```bash
npm install
npm run dev
```

Requires a Firebase project — see [`docs/FIREBASE_SETUP.md`](docs/FIREBASE_SETUP.md). Copy `.env.local.example` to `.env.local` and fill in the values.
